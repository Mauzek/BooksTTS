# BookTTS

Превращает текст книги в многоголосую аудиокнигу: размечает реплики по ролям
через Claude, синтезирует каждую своим голосом локально через Silero и
склеивает в mp3 по главам.

Работать можно двумя способами:

* **приложение** — вставил кусок текста, увидел разметку с цветом на каждой
  роли, послушал реплики поштучно, подправил голоса;
* **CLI** — скормил `.epub` или `.txt` целиком и ушёл пить чай.

Текст никуда не выгружается, кроме запроса к LLM-эндпоинту, который вы сами
указали. Синтез и склейка — полностью на вашей машине.

## Установка

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
```

Ставится в том числе `torch` (~250 МБ) — на нём работает Silero. При первом
синтезе докачается сама модель, ещё около 40 МБ.

**ffmpeg** нужен только для mp3. Системный ставить не обязательно: в
зависимостях есть `imageio-ffmpeg`, который приносит свой бинарник. Если
ffmpeg не найдётся вообще, главы сохранятся в wav, и программа об этом скажет.

### Ключи

Скопируйте `.env.example` в `.env` и заполните:

```ini
ANTHROPIC_API_KEY=sk-...
ANTHROPIC_BASE_URL=          # пусто — официальный api.anthropic.com
```

`ANTHROPIC_BASE_URL` задаётся, если вы ходите через Claude-совместимый прокси.
Проверить, что эндпоинт отвечает и какие у него модели:

```bash
python -m audiobook models
```

## Приложение

```bash
python -m audiobook serve
```

Откроется на http://127.0.0.1:8000.

1. Вставьте текст главы. Под полем показывается, сколько будет абзацев и
   сколько запросов к модели — это считается бесплатно, без обращения к LLM.
2. **Разметить по ролям** (или Ctrl+Enter). Каждая реплика получает цвет своей
   роли; переключатель сверху меняет вид на сплошной текст, где видно, не
   разорвана ли фраза.
3. Справа — список ролей. Клик по роли оставляет на виду только её реплики.
   Карандаш переименовывает; если новое имя совпадает с существующей ролью,
   они сливаются. Переименование бесплатное — оно не требует повторной
   разметки — и запоминается: следующая вставка уйдёт в модель уже со списком
   известных имён.
4. Под каждой ролью — выпадающий список дикторов и темп речи. Голоса
   предложены по имени персонажа, но **синтез заблокирован, пока вы не нажмёте
   «Подтвердить голоса»**. После этого назначения пишутся в `voices.yaml`, и
   CLI будет использовать тот же расклад.
5. ▶ у реплики озвучивает её одну. **Озвучить всё** проходит главу целиком с
   прогрессом, **Склеить в файл** собирает mp3 и даёт ссылку на скачивание.

## CLI

```bash
# что нашлось в файле: главы, абзацы
python -m audiobook parse book.epub --show 5

# разметка по ролям (только разметка, для ревью)
python -m audiobook roles book.epub --chapters 1-5 --print all

# кто говорит в книге и какими голосами
python -m audiobook voices book.epub
python -m audiobook voices book.epub --write   # записать предложенные в voices.yaml

# полная сборка
python -m audiobook build book.epub --out ./audio --chapters 1-5
```

`build` не начнёт синтез, пока каждой роли не назначен голос. Либо сначала
`voices --write` и правка файла руками, либо `build --auto-voices`, чтобы
согласиться с предложенными.

### Что кешируется

| Что | Где | Когда пересчитывается |
|---|---|---|
| Разметка по ролям | `<книга>.roles.json` | если изменился текст главы |
| Синтез реплики | `cache/tts/<хеш>.wav` | если изменился текст или голос |
| Собранная глава | `<out>/глава-NNN.mp3` | по `--force` |

Из этого получается resume: упало на сороковой главе — следующий запуск
пройдёт первые тридцать девять по кешу и продолжит с сороковой. Правка одной
реплики не заставляет переозвучивать остальные.

## voices.yaml

```yaml
narrator: { engine: silero, speaker: aidar, rate: 1.0 }
Рудеус:   { engine: silero, speaker: eugene, rate: 1.05 }
Роксана:  baya          # краткая запись: только имя диктора
default:  { engine: silero, speaker: baya }   # необязательный общий голос
```

Дикторы Silero: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`. `rate` — темп,
от 0.5 до 2.0.

### Версия модели Silero

По умолчанию берётся `v5_5_ru`. У неё те же пять дикторов, что у старой
`v4_ru`, но чище звук: у v4 слышен металлический призвук, особенно заметный
на `aidar`. Сменить версию:

```bash
python -m audiobook build book.epub --silero-model v4_ru
python -m audiobook serve --silero-model v5_2_ru
```

Доступны `v5_5_ru`, `v5_4_ru`, `v5_3_ru`, `v5_2_ru`, `v5_1_ru`, `v5_ru`,
`v4_ru`, `v3_1_ru`. Версия входит в ключ кеша синтеза: после переключения
реплики переозвучиваются, а старые файлы в `cache/tts` можно удалить. `engine: elevenlabs` берёт `speaker` как voice\_id и требует
`ELEVENLABS_API_KEY` в `.env`; бесплатный тариф ограничен 10 000 символов в
месяц, и по исчерпании синтез этой роли остановится с внятной ошибкой.

Если задан `default`, он покрывает все роли разом, и подтверждать голоса
по одной не придётся.

## Когда что-то идёт не так

Молча ничего не теряется.

* **Сбой API.** Три попытки с экспоненциальной паузой (429 уважает
  `retry-after`). После этого абзацы батча уходят рассказчику с пометкой
  `fallback`, а не выпадают из книги.
* **Неверный ключ или модель.** Прогон обрывается сразу: иначе книга на тысячу
  батчей молча уехала бы в один голос.
* **Модель пересказала абзац вместо разметки.** Если реплики покрывают меньше
  60% символов абзаца, берётся исходный текст с пометкой `recovered`.
* **Реплика не озвучилась.** Глава всё равно соберётся, пропуск попадёт в
  `<out>/отчёт.txt` и в ответ приложения.

## Известные ограничения

* Подсказка голоса считается от хеша имени и про пол персонажа ничего не знает:
  «Велимир» вполне может получить женский голос. Поправьте в панели ролей или
  в `voices.yaml` — выбор запомнится.
* Сокращения нечёткое сравнение имён не ловит. «Рудэус» сольётся с «Рудеусом»
  само, а «Руди» — нет: для таких случаев в `<книга>.roles.json` есть секция
  `aliases`, которую можно править руками.
* Silero читает по-русски. Для другого языка нужен другой бэкенд.
