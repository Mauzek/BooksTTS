# BookTTS

Настольное приложение, которое превращает книгу в многоголосую аудиокнигу:
размечает реплики по персонажам через Claude, озвучивает каждого своим голосом
и собирает главы в m4b с оглавлением или в mp3.

- **Библиотека** — папки любой вложенности, txt / epub / fb2 / docx / pdf,
  поиск по названиям и тексту глав, ручная правка границ глав.
- **Разметка по ролям** — вся книга одной кнопкой; редактор, где реплику можно
  переназначить выделением мыши, разделить, склеить, отменить.
- **Голоса** — Silero локально, ElevenLabs по ключу, Qwen3-TTS на видеокарте.
  Автоподбор учитывает пол персонажа: он определяется по тексту
  («сказал Терех», «Аглая усмехнулась»).
- **Озвучка** — очередь, которая переживает закрытие приложения; переозвучивается
  только то, что изменилось; словарь произношений для имён и терминов.
- **Плеер** — текст и звук рядом с подсветкой текущей реплики, скорость
  0,5–3×, пропуск пауз, таймер сна, позиция запоминается для каждой книги.
- **Экспорт** — m4b с главами и обложкой, mp3 по главам, разметка в JSON,
  чтобы поделиться готовым «кастингом».

Текст книги уходит наружу только в двух случаях: в Claude для разметки и в
облачный синтез, если вы выбрали ElevenLabs. Всё остальное — на вашей машине.

## Установка

Скачайте установщик из [Releases](../../releases/latest) и запустите.
Нужна Windows 10 или 11. Дальше приложение обновляется само: оно проверяет
последний релиз и ставит только пакет, подписанный ключом проекта.

При первой озвучке Silero докачает свою модель (около 60 МБ).

Для разметки по ролям нужен ключ Anthropic: **Настройки → Ключи API**. Ключ
хранится в системном хранилище паролей Windows, а не в файле. Если вы ходите
через Claude-совместимый прокси, его адрес вписывается там же, в разделе
«Разметка по ролям».

### Qwen3-TTS

Необязательный движок: девять выразительных голосов, которые передают эмоцию
реплики интонацией. Нужна видеокарта NVIDIA с 6 ГБ памяти или больше; модель и
окружение занимают около 10 ГБ на диске и ставятся в `%LOCALAPPDATA%\BookTTS-qwen`
отдельно от приложения:

```powershell
powershell -ExecutionPolicy Bypass -File desktop\install-qwen.ps1
# или на другой диск — тогда ту же папку указать в Настройках -> Папка Qwen3-TTS
powershell -ExecutionPolicy Bypass -File desktop\install-qwen.ps1 -Root E:\programs\llm\BookTTS-qwen
```

Окружение и модель живут в одной папке, её можно переносить целиком.

Qwen медленнее Silero, поэтому реплики идут пачками. Замер на RTX 3070, модель
1.7B:

| Режим | Скорость | Видеопамять |
|---|---|---|
| по одной реплике | 0,15× реального времени | 4,0 ГБ |
| пачкой по 8 | 0,78× реального времени | 5,1 ГБ |

Десятичасовая книга — примерно ночь работы в фоне. Silero на процессоре идёт
в шесть раз быстрее реального времени: удобно для черновой озвучки.

## Где лежат данные

`%APPDATA%\BookTTS`: база `library.db`, копии книг, озвучка, экспорт. Пути
внутри относительные — папку можно перенести целиком.

## Разработка

Python 3.11 и Rust (для оболочки).

```bash
pip install -r requirements.txt pytest
python -m pytest tests -q         # тесты не ходят в сеть и не тратят деньги
python -m audiobook serve         # интерфейс в браузере: http://127.0.0.1:8000
```

Окно приложения с бэкендом прямо из исходников:

```powershell
powershell -File desktop\dev.ps1
```

`target/` Rust и сборка бэкенда уходят в `%LOCALAPPDATA%\BookTTS-build` —
проект может лежать в OneDrive, и гигабайты артефактов там синхронизировались бы.

### Устройство

```
audiobook/
  paths.py        единственное место, где живут пути
  core/           логика; не знает ни про HTTP, ни про интерфейс
    db.py         схема SQLite и миграции
    repo.py       единственный модуль с SQL
    engines/      движки синтеза: новый движок — один файл
    markup.py     разметка по ролям через Claude
    synth.py      озвучка глав, отпечатки реплик, склейка
    jobs.py       очередь фоновых задач
  api/app.py      тонкий слой HTTP
  web/            интерфейс: ES-модули без сборщика, иконки Lucide
desktop/
  src-tauri/      оболочка Tauri: запускает бэкенд, обновления
  backend.spec    сборка бэкенда в exe (PyInstaller)
```

Всё состояние — в SQLite. Оболочка запускает бэкенд на свободном порту с
одноразовым токеном; бэкенд завершается сам, когда оболочка закрывается.

## Релиз

```powershell
powershell -File desktop\build.ps1   # установщик на этой машине
```

Опубликовать: поднять версию в `desktop/src-tauri/tauri.conf.json`,
`desktop/src-tauri/Cargo.toml` и `audiobook/__init__.py`, затем

```bash
git tag v0.3.0
git push origin v0.3.0
```

CI (`.github/workflows/release.yml`) прогонит тесты, соберёт установщик и
выложит релиз с `latest.json` — по нему установленные копии найдут обновление.
В секретах репозитория должны быть `TAURI_SIGNING_PRIVATE_KEY` (содержимое
ключа подписи) и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`.
